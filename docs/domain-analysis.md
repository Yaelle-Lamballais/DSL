## **Concepts** : jeu de bloquage, poser des tuiles (de formes définies) sur un plateau afin d'empêcher l'adversaire de jouer. Le joueur qui ne peut plus poser de pièce a perdu.

## **Variantes** : 
- nombre de joueur.euse.s
- taille et forme des tuiles
- contraintes sur le plateau : taille, forme, cases grisées...
- contraintes sur le placement des tuiles : seulement verticale/horizontale, impossible de poser à côté d'une de ses tuiles
- nouvelles modalités de victoire : tuiles difficiles à poser qui rapportent des points

## **Description de Ludii** : 
- 2 joueur.euse.s par partie
- liste définie de mouvements : poser une tuile
- description du plateau de jeu : forme, couleur, taille...
- ...
