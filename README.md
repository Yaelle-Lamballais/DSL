# DSL

Notre groupe est composé de Léna BEUST, Jeanne BILLON, Yaëlle LAMBALLAIS et Visaki NITHIANANTHAM.
Nous avons choisi de nous pencher sur la famille des jeux de bloquage, et plus précisément les jeux consistant à poser des tuiles sur un plateau, en empêchant l'adversaire de poser les siennes. La taille et la forme du plateau peuvent varier, comme celles des tuiles.


- **exemples de jeux** : 
	- col : https://ludii.games/details.php?keyword=Col
	- amazon : https://ludii.games/details.php?keyword=Amazons
	- domineering : https://ludii.games/details.php?keyword=Domineering
	- blocus
	
	
> [!IMPORTANT]
> Faire correspondre une variante que l'on pourra faire avec notre DSL aux jeux sur ludii (à vérifier que c'est possible en observant les descriptifs informels des jeux cités).
